# 자연어 → Notion 캘린더

"내일 오후 3시 팀 회의 1시간" 처럼 입력하면 Claude가 날짜·시간을 해석해 Notion 데이터베이스에 일정을 추가합니다.
Notion 캘린더(Notion Calendar 앱)에 해당 데이터베이스를 연결해 두면 바로 캘린더에 표시됩니다.

**API 키가 필요 없습니다.** Claude 호출은 Claude Code CLI(`claude -p`)를 통해 Claude Pro/Max 구독으로 처리됩니다.

저장소: https://github.com/bitkoji/notion-calendar-quick-add-with-claude

## 준비물

- **Windows** (크롬 확장용 로컬 프로그램을 Windows 레지스트리에 등록합니다. 명령줄 사용은 다른 OS에서도 됩니다)
- **Python 3.9 이상** (python.org 설치본의 `py` 실행기)
- **Chrome** 또는 **Edge**
- **Claude Code** + Claude Pro/Max 로그인: https://claude.com/claude-code
- **Notion** 계정

## 1. 설치

프로젝트를 내려받습니다 (또는 GitHub에서 **Code → Download ZIP**을 받아 압축을 풉니다):

```powershell
git clone https://github.com/bitkoji/notion-calendar-quick-add-with-claude.git
cd notion-calendar-quick-add-with-claude
py -m pip install -r requirements.txt
copy .env.example .env
```

설치 후에는 폴더 위치를 그대로 두세요. 옮겼다면 `install_host.py`를 다시 실행해야 합니다(4번의 3단계).

Claude Code가 설치되어 있고 Pro 계정으로 로그인되어 있어야 합니다. `claude auth status`에서 `"subscriptionType": "pro"`가 보이면 준비된 것입니다. 로그인되어 있지 않으면 `claude`를 실행한 뒤 `/login`을 입력하세요.

## 2. Notion 준비

1. **API 연결(Connection) 토큰**: https://www.notion.so/profile/integrations (개발자 도구 → 연결) → `+ 새 연결` → 이름 입력, 워크스페이스 선택 → 만든 연결 옆 `•••` → **API 토큰 복사** → `.env`의 `NOTION_TOKEN`
   (Notion이 예전 "통합(Integration)"을 "연결(Connection)"로 이름을 바꿨습니다. Free/Plus 요금제는 워크스페이스 소유자만 만들 수 있습니다.)
2. **데이터베이스**
   - Notion에서 캘린더용 데이터베이스(제목 + **날짜** 속성)를 만들거나 기존 것을 사용
   - 데이터베이스 페이지 오른쪽 위 `•••` → `더 보기` → **연결** → `연결 추가` → 방금 만든 연결 선택 (빠뜨리면 404 오류)
   - 데이터베이스 링크 `https://www.notion.so/xxxx/<32자리ID>?v=...` 에서 `<32자리ID>`를 `NOTION_DATABASE_ID`에 입력
3. (선택) Notion Calendar 앱 → 설정 → Notion → 해당 데이터베이스 표시

## 3. 사용

```powershell
py notion_cal.py "다음 주 금요일 저녁 7시 강남역에서 친구랑 저녁"
py notion_cal.py "12월 24일부터 26일까지 제주도 여행"
py notion_cal.py "내일 10시 치과, 모레 오후 2시~4시 프로젝트 리뷰"   # 여러 일정 한 번에
py notion_cal.py "내일 치과 예약 취소해줘"                         # 일정 삭제
py notion_cal.py "수요일 팀 회의 다음날로 옮겨줘"                     # 일정 옮기기
py notion_cal.py                 # 대화형 모드 (계속 입력)
py notion_cal.py -y "..."        # 확인 없이 바로 추가
py notion_cal.py --dry-run "..." # 해석 결과만 보기 (Notion 설정 불필요)
```

## 4. 크롬 확장 프로그램

툴바의 확장 아이콘을 누르면 "어떤 일정을 노션 캘린더에 추가하시나요?" 입력창이 열립니다.
입력 후 Enter → 해석된 일정 확인(체크박스로 선택) → **노션에 추가 / 삭제 / 반영**.

- **취소**: "내일 치과 취소해줘" → 해당 날짜에서 제목에 '치과'가 들어간 일정을 찾아 삭제 후보로 보여줍니다.
  날짜를 말하지 않으면 오늘부터 1년 안에서 찾습니다. 일치하는 일정이 없으면 같은 기간의 일정을 선택 해제 상태로 보여주니 직접 고르면 됩니다.
- **옮기기**: "수요일 회의 다음날로 옮겨줘", "회의 1시간 뒤로 미뤄줘", "회의 금요일 오전 10시로 바꿔줘"
  → 노션에 있는 원래 일정의 실제 시간을 기준으로 새 시간을 계산합니다(소요 시간 유지). 기존 페이지의 날짜만 바꾸므로 페이지 내용은 그대로입니다.
- 요청을 해석할 때 다가오는 일정 목록(최근 1주 ~ 앞으로 60일)을 Claude에게 함께 보여줘, 어떤 일정을 말하는지 정확히 고르게 합니다.
- 삭제된 일정은 Notion 휴지통으로 이동하며 30일 안에 복구할 수 있습니다.
- **이번 주 일정**: 팝업을 열면 이번 주 일정을 지남(✓) · 진행 중(●) · 예정(→)으로 구분해 보여 줍니다. 누르면 노션에서 열립니다. 설정 페이지(이번 주 일정 표시)에서 날짜별 목록, 요일별 캘린더, 숨기기 중에서 고를 수 있습니다. 한 주는 기본으로 월요일에 시작하고, 데이터베이스 속성 → 한 주의 시작에서 바꿀 수 있습니다 (요청의 "이번 주", "다음 주"도 이 기준).
- **중복·겹침 알림**: 같은 시각에 같은 제목의 일정이 이미 있으면 미리보기에 알리고 체크를 풀어 둡니다. 다른 일정과 시간이 겹치면 "이 시간에 '팀 회의'(15:00 ~ 16:00) 일정이 있습니다"처럼 알려 주되 체크는 유지합니다. 명령줄은 중복을 건너뛰고 겹침을 알려 줍니다.
- "내일 3시 회의"처럼 오전인지 오후인지 알 수 없으면 미리보기에 **오전 3:00 / 오후 3:00** 버튼이 나오고, 고르기 전에는 반영되지 않습니다. 명령줄에서도 똑같이 묻습니다.
- 추가한 뒤 결과 메시지에는 일정마다 시간과 **웹으로 세부 내용 추가 / 앱으로 세부 내용 추가 / 삭제**가 나와서, 잘못 추가한 일정을 바로 지울 수 있습니다.
- **복구**: 결과 메시지에서 삭제한 일정(제목 옆에 시간 표시) 아래의 **되돌리기**를 누르거나, 팝업 아래쪽 **최근 삭제한 일정**을 펼쳐 **복구**를 누릅니다.
  잘못 복구했으면 **다시 삭제**를 누르세요. **×**는 목록에서만 지웁니다 (노션은 그대로).
  목록에는 이 확장으로 최근 30일 안에 삭제한 일정이 보입니다 (노션 API로는 휴지통을 검색할 수 없어서, 확장이 브라우저에 기록해 둡니다). 설정한 데이터베이스의 일정만 복구합니다.
- "방금 추가한 일정 삭제해줘"도 됩니다: 최근에 만든 일정 10개를 만든 시각과 함께 Claude에게 보여 줍니다.

설치 (최초 1회):
1. 위의 1~2단계(`.env` 설정)를 먼저 끝냅니다.
2. 크롬에서 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기 → **압축해제된 확장 프로그램을 로드합니다** → 프로젝트 폴더 안의 `extension` 폴더 선택
3. 표시된 확장 프로그램 **ID**(영문 32자)를 복사해 등록 명령을 실행합니다.
   ```powershell
   py install_host.py <확장프로그램 ID>
   ```
   (확장 팝업을 열면 이 명령이 ID까지 채워진 채로 안내됩니다.)
4. 툴바의 퍼즐 아이콘에서 핀을 꽂아 두면 편합니다.
5. **단축키**: Chrome 창이 앞에 있을 때 `Ctrl+Shift+Y`를 누르면 입력 창이 열립니다. 바꾸려면 설정 → 단축키 → **단축키 바꾸기**를 누르세요 (`chrome://extensions/shortcuts`가 열립니다).
   설정 페이지에 단축키가 설정되지 않았다고 나오면 다른 확장이 같은 조합을 쓰는 것이고, 눌러도 반응이 없으면 다른 프로그램이 쓰는 것입니다. 두 경우 모두 다른 조합으로 바꿔 주세요.

**설정 페이지**: 팝업 오른쪽 위 톱니바퀴(또는 확장 아이콘 우클릭 → 옵션)에서 Claude 모델·언어(한국어/English)·타임존·노션 토큰·데이터베이스·속성을 바꿀 수 있습니다.
언어는 확장 화면과 오류 메시지에 적용되며, 다른 설정처럼 **저장**을 눌러야 바뀝니다(`.env`가 아니라 확장에 저장됨). 처음에는 크롬 언어가 한국어면 한국어, 그 외에는 영어로 시작합니다.
타임존은 기본이 "PC 시간대 자동"으로, 확장이 운영체제 시간대(예: `America/New_York`)를 알려줍니다. 설정 페이지에서 직접 고르면 그 값이 `.env`에 저장되어 우선합니다. (명령줄 `notion_cal.py`는 `.env`에 타임존이 없으면 `Asia/Seoul`을 씁니다.)
저장하면 `.env`에 기록되어 확장과 명령줄이 같은 설정을 씁니다. 토큰은 일부도 화면에 표시되지 않고(저장 여부만 표시), 비워 두고 저장하면 기존 토큰이 유지됩니다.
데이터베이스 칸에는 노션 링크를 그대로 붙여 넣어도 되고, "연결 확인"을 누르면 속성 목록을 불러옵니다.

구조: 확장 프로그램 → Chrome Native Messaging → `native_host/host.py` → `claude -p`(Pro 구독) + Notion API.
등록 해제는 `py install_host.py --uninstall`. 폴더를 옮기면 3번을 다시 실행하세요.

**업데이트**: 확장이 하루에 한 번 [GitHub 릴리스](https://github.com/bitkoji/notion-calendar-quick-add-with-claude/releases)의 최신 버전을 확인해, 새 버전이 있으면 팝업 위에 "새 버전 X가 있습니다"를 보여 줍니다. 버전만 조회하며 개인 정보나 일정은 보내지 않습니다. 설정 페이지(업데이트 → 새 버전 자동 확인)에서 끌 수 있고, **지금 확인**으로 바로 확인할 수도 있습니다.
업데이트하려면 프로젝트 폴더에서 `git pull` 하거나 zip을 다시 받은 뒤, `chrome://extensions`에서 확장의 새로고침(↻)을 누르세요.

## 동작 방식

- `claude -p`에 JSON 스키마(`--json-schema`)를 넘겨 일정 목록을 구조화된 형태로 받습니다. 도구·MCP·사용자 설정은 꺼서 가볍게 실행하며, 한 번에 약 5초 걸립니다.
- 현재 시각·타임존(기본 `Asia/Seoul`)을 기준으로 상대 날짜를 계산합니다. 시간이 없으면 종일 일정, 소요 시간이 없으면 1시간으로 가정합니다.
- 실행 시 환경변수 `ANTHROPIC_API_KEY`는 제거합니다. 키가 있으면 구독 대신 API로 과금되기 때문입니다.
- 사용량은 Pro 요금제 한도(claude.ai·Claude Code와 공유)에서 차감됩니다.
- 데이터베이스의 제목/날짜 속성은 자동 감지합니다. 이름을 직접 지정하려면 `.env`의 선택 항목을 사용하세요.
- **장소**("ML206", "강남역 스타벅스" 등)는 데이터베이스의 텍스트 속성 `위치`에 입력한 그대로 저장됩니다.
  데이터베이스에 `위치`(또는 `장소`, `Location`) 이름의 **텍스트** 속성을 하나 만들어 두세요(없으면 페이지 본문에 "장소: …"로 적습니다).
  참고: Notion Calendar 일정 창의 기본 "위치" 칸은 Google 캘린더 일정 전용이라, 노션 데이터베이스 일정에서는 `위치` 속성으로 보입니다.
- 메모는 `NOTION_DESCRIPTION_PROPERTY`(텍스트 속성)에, 지정하지 않으면 페이지 본문에 기록됩니다.
- 개인 사용 용도입니다. 구독 로그인을 이용해 다른 사람에게 서비스로 제공하는 것은 Anthropic 약관상 허용되지 않습니다.
